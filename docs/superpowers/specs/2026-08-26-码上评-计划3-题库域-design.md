# 码上评 · 计划 3 设计：题库域

日期：2026-08-26
状态：已与需求方逐节确认
前置：计划 2（课程域与注册体系）已完成并合入 main（73/73 绿）；本设计基于总规格 §4 题库管理与 §6 数据模型细化，并**修订**其中一处结构性设计（见 §2 修订说明）

---

## 1. 背景与目标

计划 2 交付了课程域与注册闭环。计划 3 建立题库域：教师维护自己的题目资产（Markdown 题面 + 样例/隐藏测试点），课程按需选题入库，学生获得平台级自由练习入口。同时落地终审遗留项：`user` 表补 email 列。

## 2. 已确认决策与修订说明

| # | 决策 | 结论 |
|---|---|---|
| D1 | **题目与课程解耦** | 题目是独立实体挂教师（`problem.teacher_id`），不再挂课程；首页题库模块供学生自由练习，课程从教师名下选题入班 |
| D2 | 所有权与可见性 | 私有 + 公开开关：默认仅属主可见可用；`is_public=1` 进入平台题库供所有登录学生/教师浏览练习 |
| D3 | 课程选题语义 | **引用式** `course_problem` 关联表：题目修订即时同步所有选了它的课；配套"被引用禁删"保护 |
| D4 | 删除语义 | 物理删除（测试点级联）；仅当未被任何课程引用时可删 |
| D5 | 语言空值语义 | `allowed_languages` 空 = C/C++/Java/Python 全支持；非空 = 白名单子集 |
| D6 | 资源上限 | 每题 ≤50 测试点；单点 input 与 expected_output 各 ≤64KB（UTF-8 字节）|
| D7 | MD 渲染职责 | 后端只存 Markdown 原文原样返回；前端用不注入 HTML 的安全渲染器（如 react-markdown）展示 |
| D8 | 学生端范围 | 本期交付只读 API（公开题库浏览 + 练习视图含样例点完整输入输出）；提交评测待计划 5 判题引擎 |
| D9 | 测试点保存形态 | 单条 CRUD（POST/PUT/DELETE），展示顺序 = id 升序 |

**对总规格（2026-08-24）的修订**：
- §4 教师端"题库管理：题目增删改查、测试用例管理"→ 补充为"私有题库 + 公开开关 + 课程选题（引用式）"；§5.4 学生端新增"平台题库自由练习（只读）"
- §6 数据模型 `Problem·course_id` → `Problem·teacher_id` + `course_problem` 关联表；作业域改为从课程已选题目范围内出题
- 原"题目直接挂课程下"方案随 D1 作废

## 3. 范围

### 交付内容
1. 教师私有题库：题目 CRUD + 公开开关 + 分页关键词检索
2. 测试点管理：单条 CRUD，样例/隐藏标记，数量与大小上限校验
3. 课程选题：选入/移出/已选列表（引用式，含禁删保护）
4. 学生端只读 API：公开题库浏览 + 练习视图
5. V3 迁移：`problem`/`test_case`/`course_problem` 三表 + `user.email` 列；注册流程同事务写入 email

### 非目标（明确不做）
- 自由练习的提交与评测（计划 5 判题引擎）
- 题目复制、难度标签、标签体系、全文搜索
- 课程内手动排序 API（`sort_order` 字段本期按选入顺序赋值，重排留待前端阶段）
- ADMIN 内容运营 / 官方题库层
- 删课（维持计划 2 决定，作业域后统一定义）

## 4. 数据模型（V3 迁移，单文件）

```sql
-- 终审遗留项同车：user 补 email 列（账号恢复前提；唯一索引允许多 NULL）
ALTER TABLE `user`
    ADD COLUMN `email` VARCHAR(100) NULL,
    ADD UNIQUE KEY `uk_user_email` (`email`);

CREATE TABLE `problem` (
    `id`                BIGINT       NOT NULL AUTO_INCREMENT PRIMARY KEY,
    `teacher_id`        BIGINT       NOT NULL COMMENT '属主教师',
    `title`             VARCHAR(200) NOT NULL,
    `description`       MEDIUMTEXT   NOT NULL COMMENT 'Markdown 原文，由前端安全渲染',
    `allowed_languages` VARCHAR(100) NULL COMMENT '逗号分隔语言键；NULL=全支持',
    `time_limit_ms`     INT          NOT NULL DEFAULT 1000,
    `memory_limit_mb`   INT          NOT NULL DEFAULT 256,
    `is_public`         TINYINT      NOT NULL DEFAULT 0 COMMENT '1=进入平台题库供自由练习',
    `created_at`        DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`        DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    KEY `idx_problem_teacher` (`teacher_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE `test_case` (
    `id`              BIGINT   NOT NULL AUTO_INCREMENT PRIMARY KEY,
    `problem_id`      BIGINT   NOT NULL,
    `input`           TEXT     NOT NULL COMMENT 'UTF-8 ≤64KB',
    `expected_output` TEXT     NOT NULL COMMENT 'UTF-8 ≤64KB',
    `is_sample`       TINYINT  NOT NULL DEFAULT 0 COMMENT '样例点=学生可见完整输入输出',
    `created_at`      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    KEY `idx_testcase_problem` (`problem_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE `course_problem` (
    `id`         BIGINT   NOT NULL AUTO_INCREMENT PRIMARY KEY,
    `course_id`  BIGINT   NOT NULL,
    `problem_id` BIGINT   NOT NULL,
    `sort_order` INT      NOT NULL DEFAULT 0 COMMENT '本期按选入顺序赋值',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY `uk_course_problem` (`course_id`, `problem_id`),
    KEY `idx_course_problem_pid` (`problem_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

要点：
- **语言键** `{C, CPP, JAVA, PYTHON}` 子集白名单校验，CSV 存储；C/C++ 在判题镜像层的语义由计划 5 锁定，本域不锁死
- `description` MEDIUMTEXT，应用层校验非空且 ≤128KB
- `test_case.input/expected_output` 用 TEXT（上限恰 64KB），应用层按 UTF-8 字节数校验 ≤65536
- `course_problem.pid` 索引服务于删除前的反向引用检查
- 注册建号同一事务把验证过的邮箱写入 `user.email`（RegisterService 小改）

## 5. API 设计

### 教师端·题目 CRUD（hasRole('TEACHER')，归属链 problem.teacher_id==uid 否则 40400）

| 接口 | 行为 |
|---|---|
| `POST /api/problems` | 建题：title/description 必填；allowedLanguages 缺省=全支持；time/memory 缺省 1000ms/256MB；isPublic 默认 false |
| `GET /api/problems?page&size&keyword` | 我的题目分页（含未公开），keyword 匹配标题 |
| `GET /api/problems/{id}` | 详情 + 全部测试点（属主视角，含隐藏点）|
| `PUT /api/problems/{id}` | 改基本信息（传什么改什么，语义同课程 PUT）|
| `DELETE /api/problems/{id}` | 物理删除（测试点级联）；被任一课程选用 → 40015 |

### 教师端·测试点单条 CRUD（同归属链）

| 接口 | 行为 |
|---|---|
| `POST /api/problems/{id}/test-cases` `{input, expectedOutput, isSample}` | 新增；第 51 个点或单点超 64KB → PARAM_INVALID |
| `PUT /api/problems/{id}/test-cases/{testCaseId}` | 修改（校验规则同上）|
| `DELETE /api/problems/{id}/test-cases/{testCaseId}` | 删除单点 |

展示顺序 = id 升序（录入顺序）。

### 教师端·课程选题（复用 CourseService.getOwned 课程归属链）

| 接口 | 行为 |
|---|---|
| `POST /api/courses/{courseId}/problems` `{problemId}` | 选入：只能选自己名下的题（他人题/不存在 → 40400 隐藏存在性）；已在班 → 40402；sort_order = 当前 max+1 |
| `GET /api/courses/{courseId}/problems?page&size` | 已选列表：题目摘要 + 测试点计数 + sort_order |
| `DELETE /api/courses/{courseId}/problems/{problemId}` | 移出（只删关联不动题）|

### 学生端·自由练习（只读，hasAnyRole('STUDENT','TEACHER')）

| 接口 | 行为 |
|---|---|
| `GET /api/practice/problems?page&size&keyword` | 平台公开题库（仅 is_public=1）：摘要列表（不含 MD 正文）|
| `GET /api/practice/problems/{id}` | 练习视图：MD 原文 + 语言集合 + 时空限制 + **样例点完整输入输出**；隐藏点不出现在响应任何位置；非公开/不存在 → 40400 |

## 6. 权限边界

1. 题目归属链：题目类操作校验 `problem.teacher_id == uid`，不匹配返回 40400（隐藏存在性，沿用课程域惯例）
2. 课程选题双重归属：先过 `CourseService.getOwned`（课程门）再校验题目属主（题门）
3. 学生触达教师接口 → 403（既有安全链覆盖）；学生访问私有题任何接口 → 40400
4. ADMIN 不进题目域；practice 只读接口开放 STUDENT+TEACHER
5. 隐藏测试点的输入输出永不进入任何学生可达响应（总规格 §9 红线）

## 7. 错误码新增

| 码 | 常量 | 含义 |
|---|---|---|
| 40015 | PROBLEM_IN_USE | 题目已被课程选用，无法删除 |
| 40402 | COURSE_PROBLEM_DUPLICATE | 该题目已在本课程中 |

复用：40400 NOT_FOUND（题目/课程不存在或非属主）、PARAM_INVALID（超限/白名单非法）、既有认证越权码。

## 8. 测试策略（Testcontainers 全真库，Skipped=0）

| 层 | 内容 |
|---|---|
| 归属矩阵 | 他师对题目 CRUD/测试点/选题互访全 40400；学生打教师接口 403；学生访问私有题 40400 |
| 删除保护 | 选入课程 → DELETE 40015 → 移出 → 可删；级联删测试点生效 |
| 校验规则 | 语言白名单子集与非法键拒绝、空值回显=全支持、50 点上限边界（第 50 过/51 拒）、64KB 边界（恰 65536 字节过/+1 拒）、description 128KB 上限 |
| 选题语义 | 重复选 40402、sort_order 递增、移出后可重选、列表计数正确 |
| 学生端 | practice 仅公开题可见、练习视图样例点完整输出、隐藏点零泄漏、私有题 40400 |
| 注册联动 | 注册成功后 user.email 落库断言 |
| 安全回归 | 越权样例纳入清单（他师互访、学生越界）|
