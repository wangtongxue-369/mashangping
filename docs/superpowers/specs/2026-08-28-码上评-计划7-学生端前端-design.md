## 1. 背景与问题

计划 6 之后，教师端控制台已在 UI 闭环（课程/题库/作业/成绩册），但**学生端没有任何页面**：学生能通过 `auth/login` 登录，登录后却被硬编码跳去 `/teacher/courses`，无法读题、编码、提交。一期路线图 §4 学生端功能（作业列表与题目阅读、Monaco 在线编码、判题进度实时推送、结果查看、个人成绩）全部缺失。

后端学生侧 API 已在计划 4/5 全部就绪，可直接消费；唯一缺口是**后端学生题目列表/阅读视图没返回 `assignmentProblemId`**（提交作业题的双锚之一），需要补一个小字段。

## 6. 实时判题推送（WS）契约

- **连接**：`new Client({ brokerURL: wsUrl, connectHeaders: { Authorization: 'Bearer …' } })`，`onConnect` 订阅 `/user/queue/judge-progress`。
- **事件**（`JudgeProgressEvent`）：`JUDGING`（开始判）、`POINT`（`submissionId, pointIndex, status` 逐点）、`COMPILE_ERROR`（`message`=编译错误输出）、`FINISHED`（`finalStatus, score, passedCount, totalCount`）。
- **消费**：按 `submissionId` 匹配当前等待中的提交；收到 `FINISHED` 后回填终态并失效历史查询缓存（`invalidateQueries`）。
- **最佳努力**：后端 `StompJudgeProgressPublisher` 已是 best-effort；前端 WS 连不上时提交后仅展示"排队中/已提交"，不阻断。

## 7. 数据与可见性红线（沿用既有约束）

- **隐藏测试点零泄漏**：学生视图只展示后端已过滤的 `maskedPoints`（四字段），样例点才见输入输出；前端**绝不**因缺字段自行填造。
- **作业未开始不可见题目**：后端 `requireStarted` 强制 40400/40300，前端作业卡片上标记"未开始"，不可进入题目列表（由 `status` 徽标引导，后端仍兜底）。
- **提交锚双键互斥**：作业题用 `assignmentProblemId`，练习用 `problemId`，前端提交表单二选一，不双传。
- **限流提示**：`40018 SUBMISSION_TOO_FREQUENT` 等业务错误按 `message` 友好提示，不裸抛。

## 8. 错误处理

复用计划 6 的 axios 拦截器（401→清 token 跳 `/login`；5xx→友好提示；HTTP200+`code≠0`→按 `message` 提示）。编码页提交失败显示 `message.error`，保留已输入代码不丢失（编辑器受控，提交失败不重置）。
