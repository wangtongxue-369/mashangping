# 码上评 · 计划 4 设计：作业域

日期：2026-08-26
状态：已与需求方逐节确认
前置：计划 3（题库域）已完成并合入 main（99/99 绿）；本设计基于总规格 §4 作业发布/§6 数据模型/§8 业务规则细化，衔接计划 3 的 `course_problem` 出题范围条款，并**落地**两项此前推迟的功能：删课、发布开关

---

## 1. 背景与目标

计划 3 交付了题库域与课程选题。计划 4 建立作业域：教师在课程已选题目范围内发布作业（配分值、起止时间、迟交宽限），学生按可见性规则查看作业与题目。同时清欠两笔旧账：删课功能（计划 2 起推迟，原定"作业域后统一定义"）、计划 3 终审遗留的全部绑定项（V5 外键 + 加固批）。

**边界**：本计划只做作业管理与学生只读视图。Submission 表、提交 API、判题明细、成绩册汇总与 CSV 导出全部属计划 5（依赖判题分数数据）。

## 2. 已确认决策

| # | 决策 | 结论 |
|---|---|---|
| D1 | 出题范围 | 作业从 `course_problem` 已选范围内出题；`assignment_problem` 引用 `problem_id` + 每题 `score` 分值 |
| D2 | 移出保护 | 题目被**本课程**任一作业引用后禁止从课程选题移出 → 新码 40016；引用不变量：`作业引用 ⊆ 课程选题引用` |
| D3 | 发布模型 | `is_published` 开关（默认 false），作为普通可编辑字段纳入 PUT，**无独立 publish 端点**；未发布仅教师可见（草稿），已发布对学生可见但受 start_at 时间门约束 |
| D4 | 删课 | 本次一并落地：五层级联物理删除，无保护无回收站（本期无生产数据） |
| D5 | 题目配置交互 | **批量选入** `{items:[{problemId,score}]}`（原子：任一非法全拒）+ **单条移除** + 单条改分值 PUT |
| D6 | 学生列表形态 | 按课程拉取 `GET /api/courses/{id}/assignments`，同路径按角色分流；跨课程聚合接口留计划 7 按需再加 |
| D7 | 编辑限制 | 本期不设限（标题/描述/时间/题目集合随时可改，教师自担责任）；规格预留收紧条款见 §8 |
| D8 | 时间语义 | `LocalDateTime` ISO 传输、服务器本地时区（单时区部署与既有惯例一致）；`due_at > start_at` 强制校验 |
| D9 | 迟交宽限 | `late_days` ∈ [0,7] 默认 0；宽限截止 = `due_at + late_days` 天，**不冗余存列**，实时推算 |

**对总规格（2026-08-24）的修订**：
- §6 数据模型 `Assignment·late_policy 迟交策略` → 具体化为 `late_days INT [0,7]` + `is_published TINYINT`
- §4 教师端补充"删课"；§4 学生端明确作业列表为按课程拉取 + 四态状态机
- 原"删课推迟至作业域后"条款随 D4 作废

## 3. 范围

### 交付内容
1. V5 迁移：`assignment`/`assignment_problem` 两表 + `course_problem` 补外键（计划 3 绑定义务）
2. 教师端：作业 CRUD + 发布开关 + 批量选题/移除/改分值 + 作业列表（含草稿）
3. 学生端只读 API：按课程作业列表（状态机）+ 题目列表 + 题目阅读视图（start_at 三级门）
4. 引用保护：course_problem 移出锁（40016）联动
5. 删课：五层级联物理删除
6. 清欠批：分页 clamp/@Valid/并发重复归一/keyword 转义/GROUP BY 计数/缺题跳过防御/email 冲突码

### 非目标（推迟计划 5 及以后）
- Submission 表与提交 API、提交入口开放区间校验（仅定义语义，不实现）
- 判题、成绩册汇总与 CSV 导出
- 跨课程聚合作业列表接口
- 「有提交的题不可移出作业」收紧条款（届时补一条 COUNT 生效）
- 前端删除确认框（计划 7）

## 4. 数据模型（V5 迁移，单文件）

```sql
CREATE TABLE `assignment` (
    `id`           BIGINT       NOT NULL AUTO_INCREMENT PRIMARY KEY,
    `course_id`    BIGINT       NOT NULL COMMENT '属主课程',
    `title`        VARCHAR(200) NOT NULL,
    `description`  MEDIUMTEXT   NULL COMMENT 'Markdown 作业说明，可选，≤128KB',
    `start_at`     DATETIME     NOT NULL,
    `due_at`       DATETIME     NOT NULL,
    `late_days`    INT          NOT NULL DEFAULT 0 COMMENT '迟交宽限天数 0~7',
    `is_published` TINYINT      NOT NULL DEFAULT 0 COMMENT '1=对学生可见',
    `created_at`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    KEY `idx_assignment_course` (`course_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE `assignment_problem` (
    `id`            BIGINT   NOT NULL AUTO_INCREMENT PRIMARY KEY,
    `assignment_id` BIGINT   NOT NULL,
    `problem_id`    BIGINT   NOT NULL,
    `score`         INT      NOT NULL COMMENT '该题分值 1~10000',
    `sort_order`    INT      NOT NULL DEFAULT 0 COMMENT '按选入顺序赋值',
    `created_at`    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY `uk_assignment_problem` (`assignment_id`, `problem_id`),
    KEY `idx_assignment_problem_pid` (`problem_id`),
    CONSTRAINT `fk_ap_assignment` FOREIGN KEY (`assignment_id`) REFERENCES `assignment`(`id`),
    CONSTRAINT `fk_ap_problem` FOREIGN KEY (`problem_id`) REFERENCES `problem`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 计划 3 绑定义务同车：course_problem 补外键兜底
ALTER TABLE `course_problem`
    ADD CONSTRAINT `fk_cp_course`  FOREIGN KEY (`course_id`)  REFERENCES `course`(`id`),
    ADD CONSTRAINT `fk_cp_problem` FOREIGN KEY (`problem_id`) REFERENCES `problem`(`id`);
```

要点：
- 外键均为 RESTRICT 兜底：应用层禁删/禁移出保护先行拦截，FK 只防绕过应用的脏数据；级联删除一律应用层显式按序删
- 新包 `assignment/`：Assignment/AssignmentProblem 实体 + 两 Mapper + AssignmentService/AssignmentController/AssignmentProblemController，沿用按业务域分包惯例
- 校验：title @NotBlank ≤200；description 可选 ≤128KB（UTF-8 字节，service 层校验，同题目 description 手法）；lateDays @Min(0) @Max(7)；score ∈ [1,10000]

## 5. API 设计

### 教师端（`hasRole('TEACHER')`）

归属链：所有操作经 `AssignmentService.getOwned(uid, assignmentId)` 或 `CourseService.getOwned(uid, courseId)` 单漏斗，非属主一律 40400「作业不存在/课程不存在」（隐藏存在性）。

| 接口 | 行为 |
|---|---|
| `POST /api/courses/{courseId}/assignments` | 创建；title/description/startAt/dueAt/lateDays/isPublished 语义见 §4 校验；due>start 强制 |
| `GET /api/courses/{courseId}/assignments?page&size` | 我的作业列表（含草稿），due_at 升序分页；每项附 totalScore（SUM）、problemCount（COUNT，GROUP BY 聚合）、status |
| `GET /api/assignments/{id}` | 详情：全字段 + 题目清单（problemId/title/score/sortOrder）|
| `PUT /api/assignments/{id}` | 部分更新（传什么改什么）；isPublished 在此切换；本期不设编辑限制 |
| `DELETE /api/assignments/{id}` | 物理删除，级联删 assignment_problem 行 |
| `POST /api/assignments/{id}/problems` | 批量选入 `{items:[{problemId,score}]}`：每题必须在本课程选题范围内（course_problem 成员性即隐含属主正确，不再查题属主）；越界题/重复选入/items 内重复 id → 40400 或 PARAM_INVALID；原子写入；sort_order 按 items 顺序从当前 max+1 接续递增 |
| `PUT /api/assignments/{id}/problems/{problemId}` `{score}` | 改单题分值 |
| `DELETE /api/assignments/{id}/problems/{problemId}` | 移出单题（只删关联不动题）|

### 学生端（`hasAnyRole('STUDENT','TEACHER')`，实际由 service 层 enrollment 门控制）

归属链：新建 `assertEnrolled(uid, courseId)` 辅助——enrollment 不存在 → 40400「课程不存在」（隐藏课程存在性）。教师预览学生视角不做（教师用教师端接口）。

三级可见性门：**已选课 → 已发布(is_published=1) → 已过 start_at**。

| 接口 | 行为 |
|---|---|
| `GET /api/courses/{courseId}/assignments?page&size`（同路径角色分流）| 仅已发布作业；卡片字段 id/title/startAt/dueAt/lateDays/problemCount/status |
| `GET /api/courses/{courseId}/assignments/{assignmentId}/problems` | 题目列表：problemId/title/score/sortOrder/allowedLanguages/timeLimitMs/memoryLimitMb；start_at 前 → 40300「作业尚未开始」|
| `GET /api/courses/{courseId}/assignments/{assignmentId}/problems/{problemId}` | 题目阅读视图：MD 原文 + 样例点**完整输入输出**；隐藏点零泄漏（结构隔离手法同 PracticeViews）；同样受 start_at 门 |

**状态机**（服务端实时计算，师生列表通用）：`NOT_STARTED → IN_PROGRESS → LATE_WINDOW(due~due+lateDays) → CLOSED`；实现为静态纯函数 `AssignmentStatus.of(now, startAt, dueAt, lateDays)` 可独立单测。

## 6. 权限边界

1. 教师侧双漏斗：课程维度操作过 `CourseService.getOwned`；作业维度操作过 `AssignmentService.getOwned`（内部反查课程归属）
2. 学生侧 enrollment 门覆盖全部课程作业接口；未选课 40400 隐藏课程存在性
3. 学生触达教师接口 → 403（既有安全链覆盖）
4. ADMIN 不进作业域
5. 隐藏测试点的输入输出永不进入任何学生可达响应（总规格 §9 红线，沿袭计划 3）

## 7. 错误码新增

| 码 | 常量 | 含义 |
|---|---|---|
| 40016 | PROBLEM_LOCKED_BY_ASSIGNMENT | 题目已被本课程的作业选用，无法从课程移出 |
| 40017 | EMAIL_CONFLICT | 该邮箱已被注册（清欠项：RegisterService 注册 email 撞唯一键由误归一 40013 改归一本码）|

复用：40400 NOT_FOUND（作业/课程不存在或非属主、题目不在选题范围、未选课——文案分场景）、40300 FORBIDDEN 自定义消息「作业尚未开始」、40000 PARAM_INVALID（时间倒挂/lateDays 越界/score 越界/批量含非法项）、既有认证越权码。

## 8. 引用保护与删课级联

### 移出保护链

`CourseSelectionService.remove` 前置检查：该题被**本课程**任一作业引用（`assignment_problem JOIN assignment ON a.course_id = :courseId AND ap.problem_id = :problemId` 存在行）→ 40016 PROBLEM_LOCKED_BY_ASSIGNMENT。只看本课程：题被 A 课作业引用不影响从 B 课移出。

连带推论：`ProblemService.delete` 的 40015 禁删检查（查 course_problem 引用）**无需改动**——因移出已被锁死，`course_problem` 非空 ⇔ 题目仍可能被作业引用，既有检查天然覆盖新引用面。

### 删课级联

`DELETE /api/courses/{id}`（getOwned），`@Transactional` 内按外键依赖序物理删除：

```
enrollment(该课) → assignment_problem(JOIN 该课 assignment) → assignment(该课)
→ course_problem(该课) → course
```

无删除保护、无回收站。预留收紧条款：计划 5 引入提交后，「含提交记录的课程」删除前需额外校验。

## 10. 清欠清单（T0 任务先行）

1. 分页 clamp 助手 `PageUtils`（common 包）：page≥1 归 1、size∈[1,50] 越界取边界；应用到既有 6 个分页端点（courses/courseMembers/users/courseSelections/practice/problems）+ 本计划新端点
2. `CourseSelectionController.select` 补 `@Valid`（record 上 @NotNull 当前不生效）
3. `CourseSelectionService.select` catch `DuplicateKeyException` → 归一 40402 COURSE_PROBLEM_DUPLICATE
4. keyword LIKE 通配符转义（`%`/`_`/`\`，ProblemService.listMine）
5. testCaseCount 改 GROUP BY 聚合（消除逐行计数）
6. `CourseSelectionService.list` 批量装配映射缺题跳过防御（关联行存在而题目已消失时跳过不炸）
7. RegisterService 注册 email 撞唯一键 → 40017 EMAIL_CONFLICT（替代误归一的 40013）

## 11. 与后续计划的衔接

- 计划 5（判题域）：Submission 将挂 `(assignment_id, problem_id, user_id)`；迟交判定 = `submitted_at > due_at`（宽限期内可交、标记迟交、成绩照常取最高分）；提交入口开放区间 = `[start_at, due_at + late_days]`；超期关闭提交入口
- 成绩册：按 `assignment_problem.score` 聚合同题最高分——分值配置本期已就位
- 收紧条款自动生效位：「有提交的题不可移出作业」届时在 remove 处补一条 COUNT
- 计划 7（前端）：学生 Monaco 提交页消费本题阅读视图的语言集合与时空限制；作业状态徽标直接读 status 字段；删课确认框在此补
