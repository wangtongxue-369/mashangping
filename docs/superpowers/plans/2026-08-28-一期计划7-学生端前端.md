# 计划 7 · 一期学生端前端实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐学生端全部页面与实时判题进度推送，使「在线读题 → Monaco 编码 → 提交 → 实时判题进度 → 结果查看」闭环上线；并做一处后端小改（学生题目视图补返 `assignmentProblemId`）。

**Architecture:** 复用计划 6 前端工程（`frontend/`）。新增 `/student/*` 路由树（`StudentLayout` + 可选 `role` 的角色守卫），新增 `api/studentTypes.ts` 与真实 STOMP 客户端 `api/ws.ts`（`@stomp/stompjs`）。作业与练习的「编码+提交+结果」逻辑抽公共组件 `CodingWorkspace`。后端仅改 `AssignmentViews` 两个 record 与 `StudentAssignmentService` 装配，无 DDL/迁移。

**Tech Stack:** 前端 React 18 · Vite · TS · AntD5 · TanStack Query · axios · Router6 · `@monaco-editor/react`（学生端可写）· `@stomp/stompjs`（新增）；后端 Spring Boot 3.3.4 / MyBatis-Plus / JUnit5。

## Global Constraints

- **Java17**：后端改动禁用 JDK21 API（`getFirst()` 等一律 `get(0)`）。
- **红线·隐藏测试点零泄漏**：学生视图只渲染后端已过滤的 `maskedPoints`；样例点才见输入输出；前端不因缺字段自行填造。
- **红线·作业未开始不可见题目**：前端以 `status=NOT_STARTED` 徽标引导不可进入，后端 `requireStarted` 仍兜底。
- **红线·业务错误 HTTP200 + code≠0**：沿用 axios 拦截器按 `message` 友好提示，不裸抛堆栈。
- **提交锚双键互斥**：作业题 `assignmentProblemId`、练习 `problemId`，二选一，不双传。
- **后端无迁移**：本计划不新增/修改任何 Flyway 迁移；仅改视图 record 与装配。
- **前端只做路由级守卫**，归属链/可见性全部由后端强制，前端不复制。
- 沿用教师端测试风格：独立 QueryClient + AuthProvider + 路由（含 `ProtectedRoute`）；用例与组件同目录 `*.test.tsx`。
- 代码注释/文案全中文，标识符英文；每任务提交一次 commit（conventional，type/scope 英文、描述中文）。
