# 计划 8 · 二期 P2 一期·同班代码查重 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: 执行本 plan 用 TDD 逐任务推进，步骤 checkbox 跟踪。测试命令后端在 `server/` 用 `.tools/maven/bin/mvn -f server/pom.xml -Dmaven.repo.local=<repo>`（本机无全局 mvn）；前端在 `frontend/` 用 npm。

**Goal:** 交付教师端「同题同班代码查重」：真 AST（Tree-sitter）归一化指纹 + 两两相似度报告 + 左右代码对比高亮；教师专属、即时计算+缓存、无新表迁移。

**Architecture:** 后端新领域包 `com.mashangping.plagiarism`（parser→fingerprint→engine→service→controller），复用 `Submission.code`；归属校验走 assignment 域（作业属课、课属教师）。前端教师端新增 `PlagiarismPage`（报告）与对比视图，作业详情题目行加「查重」入口。

**Tech Stack:** 后端 Spring Boot 3.3.4 / MyBatis-Plus / JUnit5+Testcontainers；新增 `io.github.bonede:tree-sitter 0.24.4` + c/cpp/java/python 语言包（已实测 mac arm64 加载）。前端 React18/AntD5/TanStack Query（沿用教师端既有风格）。

## Global Constraints

- **Java17**：禁用 JDK21 API。
- **红线·教师归属**：非属主教师一律 40400；学生角色对查重端点 403。
- **红线·学生不可见**：查重仅 TEACHER 端点；学生端零展示。
- **无新 Flyway 迁移**；不改判题链路/Submission 结构。
- **字符串字面量保留、标识符/数字归一** 为规范口径（spec §4.1）。
- **相似度语义**：sim=shingle Jaccard，默认阈值 0.80=高疑似(HIGH)、0.50~0.80=关注(MID)、<0.5 默认不入报告；阈值端点可调。
- 原生库目录：测试经 pom surefire `-Dtree-sitter-lib=${project.build.directory}/tree-sitter-lib`；运行 `-Dtree-sitter-lib=<dir>`（spec §3）。
- 前端文案中文、tsc strict；后端注释中文。
