# 计划 9 · 课程工作台 + 全站精品化 + 功能打通 实现计划

> **For agentic workers:** TDD 逐任务推进，checkbox 跟踪。后端用 `.tools/maven/bin/mvn -f server/pom.xml -Dmaven.repo.local=<repo>`；前端在 `frontend/` 用 npm/npx。

**Goal:** 教师端以「课程工作台」为中心的二级界面 + 图形化数据看板 + 全站浅色精品化 + 互链打通；后端补读聚合端点（无迁移）。

## Global Constraints
- 教师归属校验一律 40400；聚合端点 `hasRole('TEACHER')`。
- 成绩口径与 gradebook 一致（无 cell=0）；AC 率=AC 学生数/有提交学生数。
- Java17；无 Flyway 迁移；前端文案中文 + tsc strict。
- 图表组件按需加载（lazy），jsdom 测试需 mock `@ant-design/plots`。
- 每任务一 commit（conventional）。
