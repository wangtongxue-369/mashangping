# 计划 6 · 一期前端教师端实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在同仓内新建 `frontend/` 前端工程（React 18 + Vite + TS + AntD5 + TanStack Query），交付完整教师端控制台（课程/学生名单/题库/作业发布 + 提交历史/成绩册/CSV），并补齐教师端 3 个缺失后端端点。

**Architecture:** 前端为独立 Vite SPA，通过 axios 调后端 `/api/*`，dev 时 Vite proxy 转发到 Spring Boot（app 端口 8080，MySQL 3307）。后端只新增 3 个教师端补端点（成绩册矩阵/教师提交历史/CSV 导出，另加 1 个教师提交详情端点），其余复用计划 1-5 既有 API。教师端归属链校验全部在后端 service 层强制，前端只做路由级 token 守卫。

**Tech Stack:** React 18 · Vite · TypeScript · Ant Design 5 · TanStack Query · axios · React Router 6 · `@monaco-editor/react`（只读渲染）；后端沿用 Spring Boot 3.3.4 / MyBatis-Plus / JUnit5 + MockMvc + Testcontainers。

## Global Constraints

- **前端必须新增于仓库根 `frontend/` 目录**（同仓，`server/` 平级），不另立仓库。Git 提交中必须包含 `package-lock.json`。
- **Java17**：后端任何改动禁用 JDK21 API（`getFirst()`/`removeLast()`/`SequencedCollection` 一律用 `get(0)`/`get(size()-1)`）。
- **红线·隐藏测试点零泄漏**：`judge_detail.message`（RE stderr）仅在样例点对教师下发；隐藏点决不返回 message/input/expectedOutput。
- **红线·业务错误 HTTP200 + code≠0**：`ApiResponse` 的 `code`/`message` 透传；前端统一按 `message` 提示，不裸抛堆栈。
- **归属链强制**：教师只能访问自己课程之下的作业/题目/学生数据；越权用 `ErrorCode.NOT_FOUND(40400)` 语义（对齐 `CourseService`/`AssignmentService` 既有实现）。
- **成绩册语义锁定**：行=学生、列=题目、末列总分；`bestScore`=该生该题全部 submission 中 `status='AC' ? score : 0` 的最高值；未提交该题=无 cell（前端渲染 `—`）；`total`=各题 `bestScore`（含 0）之和。**前端不承担任何聚合，只渲染服务端下发的矩阵。**
- **CSV 语义**：未做/未提交格子导出**数值 0**（与前端展示的 `—` 区分）；UTF-8 **含 BOM**；服务端做 RFC4180 转义（`"` 双写、含 `,`/`"`/`\n` 包引号）与公式注入前缀防御（字段以 `=`/`+`/`-`/`@` 开头则加单引号前缀）。
- **分页钳制**：统一 `PageUtils.page()`(≥1) / `PageUtils.size()`(∈[1,50])，全部已有分页端点的响应体是 MyBatis-Plus `Page<T>`（`{records, total, size, current}`）。
- MyBatis-Plus `map-underscore-to-camel-case: true` 已全局开启，实体/视图字段一律 camelCase。
- 前端只做路由级守卫（`ProtectedRoute`），**不复制后端归属校验**；教师端点统一 `@PreAuthorize("hasRole('TEACHER')")`。

- [ ] **Step 3: 实现 `GradebookView` + `GradebookService` 聚合**

```java
// GradebookView.java —— 矩阵响应，前端只渲染不聚合
package com.mashangping.gradebook.dto;
import java.util.List;
public record GradebookView(
        long assignmentId, String assignmentTitle,
        List<StudentRow> students,
        List<ProblemRow> problems,
        List<Cell> cells,
        List<Total> totals) {
    public record StudentRow(long studentId, String studentNo, String realName) {}
    public record ProblemRow(long assignmentProblemId, long problemId, String title,
                             int score, int sortOrder) {}
    public record Cell(long studentId, long assignmentProblemId, int bestScore) {}
    public record Total(long studentId, int total) {}
}
```
要点：
- `students` = 该课程全部 `enrollment`（`status='ACTIVE'` 且 `student_id` 非空——有账号才可能提交；未激活 PENDING 无账号不可提交故不进矩阵）。`realName` 取自 `user.real_name`（enrollment.student_name 是导入快照，用于未激活展示；激活后用账号实名，对齐 `EnrollmentView.displayName` 语义）。
- `problems` = 该作业 `assignment_problem` 全列按 `sort_order` 升序。
- `cells` = 对每个 `(studentId, assignmentProblemId)`：`MAX(CASE WHEN status='AC' THEN score ELSE 0 END)`，且该生该题**有至少一条 submission** 才产出 cell（无提交则无 cell）。**注意：`submission.user_id` 与 `assignment_problem_id` 联合定位，切勿按 `assignment_id`+user 跨题混算。**
- `totals` = 每个学生各题 bestScore 之和（无 cell 计 0），仅对 enrollment 内学生。
- 归属校验：`isOwner` 检查作业属当前教师（对齐 `AssignmentService`），否则 `throw new BizException(ErrorCode.NOT_FOUND)`。
- **聚合必须走自定义 Mapper**：`SubmissionMapper extends BaseMapper<Submission>` 是裸 CRUD，没有分组聚合方法。本任务新增 `GradebookMapper extends BaseMapper<Submission>`，内含两个 `@Select` 聚合 SQL（见下），`GradebookService` 组装矩阵时用这两个查询结果拼 `cells`/`totals`，不循环查库。

```java
// GradebookMapper.java —— 成绩册聚合专用（新增文件，同一包 com.mashangping.gradebook）
package com.mashangping.gradebook;

import com.mashangping.judging.Submission;
import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Param;
import org.apache.ibatis.annotations.Select;

import java.util.List;
import java.util.Map;

@Mapper
public interface GradebookMapper extends BaseMapper<Submission> {

    /** (studentId, assignmentProblemId) 的最高有效分；无提交的 (user, ap) 组合不出现 */
    @Select("""
            SELECT s.user_id AS studentId, s.assignment_problem_id AS assignmentProblemId,
                   MAX(CASE WHEN s.status = 'AC' THEN s.score ELSE 0 END) AS bestScore
            FROM submission s
            WHERE s.assignment_id = #{assignmentId}
              AND s.assignment_problem_id IS NOT NULL
            GROUP BY s.user_id, s.assignment_problem_id
            """)
    List<Map<String, Object>> selectBestScores(@Param("assignmentId") long assignmentId);

    /** 每个学生的总分 = 各题最高有效分之和（Map 键 studentId / total）。
        必须先按 (user, ap) 取每题最高有效分再跨题累加——直接 SUM(CASE…) 会把同一题多次 AC 重复计入。 */
    @Select("""
            SELECT per.studentId, SUM(per.best) AS total
            FROM (
                SELECT s.user_id AS studentId, s.assignment_problem_id,
                       MAX(CASE WHEN s.status = 'AC' THEN s.score ELSE 0 END) AS best
                FROM submission s
                WHERE s.assignment_id = #{assignmentId}
                  AND s.assignment_problem_id IS NOT NULL
                GROUP BY s.user_id, s.assignment_problem_id
            ) per
            GROUP BY per.studentId
            """)
    List<Map<String, Object>> selectTotals(@Param("assignmentId") long assignmentId);
}
```
（若某题该生无提交：selectBestScores 不出现该组 → 无 cell，符合「无 cell 即未提交 = 数学 0」；已提交但全 WA 的组也出现，`MAX(...)=0` → cell=0，符合「WA 非 AC→0」。`total` 由 SQL 直接给出，避免前端/服务端二次聚合漂移。）

```java
// GradebookController.java
@RestController
@RequestMapping("/api/assignments/{assignmentId}")
@PreAuthorize("hasRole('TEACHER')")
@RequiredArgsConstructor
public class GradebookController {
    private final GradebookService gradebookService;

    @GetMapping("/gradebook")                       // 端点 A：矩阵
    public ApiResponse<GradebookView> gradebook(@AuthenticationPrincipal TokenPayload me,
                                                @PathVariable long assignmentId) {
        return ApiResponse.ok(gradebookService.gradebook(me.uid(), assignmentId));
    }

    @GetMapping("/submissions")                     // 端点 B：教师全局提交历史（分页）
    public ApiResponse<Page<TeacherSubmissionRow>> submissions(
            @AuthenticationPrincipal TokenPayload me, @PathVariable long assignmentId,
            @RequestParam(defaultValue="1") int page, @RequestParam(defaultValue="20") int size,
            @RequestParam(required=false) Long assignmentProblemId,
            @RequestParam(required=false) Long studentId) {
        return ApiResponse.ok(gradebookService.submissions(me.uid(), assignmentId,
                PageUtils.page(page), PageUtils.size(size), assignmentProblemId, studentId));
    }

    @GetMapping("/gradebook/csv")                   // 端点 C：CSV 导出（text/csv 附件）
    public ResponseEntity<byte[]> csv(@AuthenticationPrincipal TokenPayload me,
                                      @PathVariable long assignmentId) {
        byte[] bytes = gradebookService.csv(me.uid(), assignmentId);
        return ResponseEntity.ok()
                .contentType(new MediaType("text","csv", StandardCharsets.UTF_8))
                .header(HttpHeaders.CONTENT_DISPOSITION,
                        "attachment; filename=gradebook-" + assignmentId + ".csv")
                .body(bytes);
    }

    @GetMapping("/submissions/{submissionId}")      // 端点 D：教师提交详情（含判题明细）
    public ApiResponse<?> submissionDetail(@AuthenticationPrincipal TokenPayload me,
                                           @PathVariable long assignmentId,
                                           @PathVariable long submissionId) {
        return ApiResponse.ok(gradebookService.submissionDetail(me.uid(), assignmentId, submissionId));
    }
}
```

- [ ] **Step 4: 基础三文件 + 认证 context + 守卫实现**

```tsx
// api/client.ts
import axios from 'axios';
export const client = axios.create({ baseURL: '/api' });
client.interceptors.request.use((cfg) => {
  const t = localStorage.getItem('msp_token');
  if (t) cfg.headers.Authorization = `Bearer ${t}`;
  return cfg;
});
client.interceptors.response.use(
  (resp) => {
    const body = resp.data;
    if (body && typeof body.code === 'number' && body.code !== 0) {
      // 业务错误：HTTP200 + code≠0 —— 交调用方按 message 提示，不静默吞
      return Promise.reject(body);
    }
    return resp;
  },
  (err) => {
    if (err.response?.status === 401) { localStorage.removeItem('msp_token'); window.location.href = '/login'; }
    return Promise.reject(err);
  },
);

// auth/useAuth.ts
// AuthProvider（context）+ useAuth()：token 存 localStorage('msp_token')，
// login() 调 client.post('/auth/login',{username,password}) 存 token + user；logout() 清 token 跳 /login。
```
